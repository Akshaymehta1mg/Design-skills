# Research Plan

## Purpose

Use this subskill when the user wants to validate the UX direction, understand user needs, test a flow, or create a research approach.

## Output Format

```markdown
# Research Plan

## Research Objective
...

## Key Questions
- ...

## Hypotheses
- ...

## Participants
...

## Method
...

## Tasks Or Stimuli
- ...

## What To Observe
- ...

## Success Signals
- ...

## Risks
- ...

## Timeline
...

## Output
...
```

## Method Selection

- Use usability testing for screen or flow comprehension.
- Use interviews for needs, motivations, and mental models.
- Use concept testing for early product direction.
- Use survey only when the question is narrow and answer options are known.
- Use analytics review when behavioral data already exists.

## Rules

- Tie the plan to the product decision.
- Do not over-research low-risk changes.
- Prefer lean validation when the board is already specific.
