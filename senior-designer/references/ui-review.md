# UI Review

## Purpose

Use this subskill to critique a screen, flow, or design direction and provide actionable UX improvements.

## Review Criteria

Evaluate:

- Goal clarity.
- Information hierarchy.
- Primary action clarity.
- Flow logic.
- Copy and labels.
- Visual grouping.
- Feedback states.
- Error prevention and recovery.
- Accessibility.
- Trust and confidence.
- Consistency with surrounding product.

## Output Format

```markdown
# UX Review

## Overall Read
...

## What Works
- ...

## Main Issues
- **Issue:** ...
  **Why it matters:** ...
  **Recommendation:** ...

## Priority Fixes
1. ...
2. ...
3. ...

## Nice-To-Have Improvements
- ...

## Questions
- ...
```

## Rules

- Lead with the most important issues.
- Make every critique actionable.
- Separate critical blockers from polish.
- Do not critique visual taste unless it affects usability or product trust.
