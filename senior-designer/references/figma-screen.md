# Figma Screen

## Purpose

Use this subskill when the user wants a new or revised Figma screen, high-fidelity UI, componentized layout, or visual design output.

## Process

1. Read nearby frames and existing visual system.
2. Identify reusable components, styles, typography, spacing, and interaction patterns.
3. Define the screen purpose and primary action.
4. Create or revise the screen using the existing design direction where possible.
5. Include required states if relevant.
6. Add concise labels or annotations only if the board needs them.

## Design Rules

- Use the product's existing components and visual language first.
- Do not redesign the whole product unless asked.
- Keep the screen focused on the user's next action.
- Include realistic content.
- Make hierarchy and interaction states clear.
- Design empty, loading, error, and success states when they affect the task.
- Ensure the screen can be understood without verbal explanation.

## Rules

- If writing into Figma, use the correct Figma skill/tool workflow for file context.
- If only describing, provide a buildable screen plan.
- Avoid purely decorative changes unless they improve comprehension, trust, or task success.
