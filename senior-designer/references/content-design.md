# Content Design

## Purpose

Use this subskill when the user needs UX copy, labels, microcopy, empty states, error states, onboarding text, or content hierarchy.

## Process

1. Identify the user's moment:
   - Learning
   - Deciding
   - Acting
   - Waiting
   - Recovering
   - Confirming success

2. Identify the message job:
   - Explain
   - Reassure
   - Direct
   - Warn
   - Confirm
   - Motivate

3. Write copy:
   - Clear headline.
   - Useful body.
   - Specific action label.
   - Helpful secondary action if needed.

## Output Format

```markdown
# Content Design

## Moment
...

## Copy Recommendations

### Headline
...

### Body
...

### Primary CTA
...

### Secondary CTA
...

### Error Copy
...

### Empty State Copy
...
```

## Rules

- Use plain language.
- Make CTAs action-specific.
- Do not blame the user in error states.
- Put the most important information first.
- Match the user's confidence level.
